# Планетарное время

Бесплатный Telegram Mini App для «Акаузального Оракула». Статический HTML, CSS и JavaScript. Таблица, фазы Луны, расчёт планетарных часов и поиск места работают в браузере. Выбранное место, настройки и сигналы хранятся в хранилище браузера.

## Проверка

Из папки Mini App запустите:

~~~sh
python -m http.server 8000
~~~

Откройте http://localhost:8000. В Telegram приложению нужен публичный HTTPS. База мест требует браузер с поддержкой DecompressionStream.

## Публикация и бот

1. Опубликуйте содержимое этой папки как отдельный статический сайт. Для GitHub Pages положите файлы в корень ветки публикации. В корне должен лежать index.html.
2. Укажите публичный HTTPS-адрес папки в переменной PLANETARY_WEBAPP_URL в .env бота.
3. На виртуальной машине проверьте путь процесса и рабочий каталог. Перезапустите действующий процесс и проверьте свежую запись о polling в журнале.
4. Откройте /planetary в личных сообщениях бота. Кнопка также появляется в основном меню, при первом знакомстве и в меню для публикаций. Для отдельной ссылки t.me/<бот>/<имя> можно дополнительно зарегистрировать приложение в BotFather.

Сигналы срабатывают на открытом экране Mini App. Для звука на устройстве должен быть разрешён звук веб-приложения. Вибрация зависит от клиента Telegram и ОС.

## Расчёт и данные

Формулы Солнца, Луны и фаз перенесены из Astro.kt проекта Planetary hours. День начинается с местного восхода. В полярные периоды циферблат показывает отсутствие расчётного часа. Поиск места использует локальный архив из Planetary hours, подготовленный по данным [GeoNames](https://www.geonames.org/), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Приложение использует часовой пояс выбранного места. Начальная локация — Москва.
